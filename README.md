# Inner Lab｜心緒研究所

> 每一種情緒，都值得被安放。A little space for everything you feel.

以「心緒漂流瓶」為核心的互動式情緒創作與數位日記平台。前端是單一 `index.html`（HTML + CSS + 原生 JavaScript，無框架、無建置流程），可直接部署到 GitHub Pages；公開分享使用 Supabase（匿名驗證 + RLS），天氣使用 Open-Meteo。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 整個網站（樣式、版面、程式都在這裡，程式以 20 個區塊註解分段，第 19 區是延伸功能，第 20 區是動線與保存的打磨） |
| `assets/` | 網站縮圖的原始檔（`favicon.svg`、`apple-touch-icon.png`）。`index.html` 已經內嵌同一個圖示，不上傳這個資料夾也會顯示；若想改用檔案，寫成 `<link rel="icon" href="assets/favicon.svg">`（`href` 要指到檔案，不能只寫資料夾） |
| `supabase/schema.sql` | 雲端資料表、RLS 政策、頻率限制與檢舉自動隱藏的觸發器 |
| `docs/PLAN.md` | Phase 1 規劃：頁面架構、流程、資料模型、私人/公開分界、RLS 規劃、驗收清單與測試結果、風險 |
| `SPECIFICATION.md` | 原始規格書 |
| `tests/` | 自動化測試腳本（Playwright）：`run.js` 基本功能、`features.js` 延伸功能、`polish.js` 動線與保存，`fakesb.js` 是測試用的模擬 Supabase |
| `docs/test-screenshots/` | 自動化測試時擷取的畫面（測試環境無法連到 Google Fonts，所以字體是系統備用字，不是正式樣貌） |

## 功能一覽

- **首頁**：海洋星空場景、浮動漂流瓶、依裝置時區的日期時間與問候、天氣卡、今日短句（複製／收藏）、今日色彩、功能入口、最近紀錄、到期信件提醒。
- **漂流瓶工作室**：6 種背景場景、5 種瓶身、5 種紙條、11 種裝飾、文字框；拖曳、縮放、旋轉（滑鼠與觸控，Pointer Events）、屬性面板（位置／尺寸／角度／透明度／顏色）、圖層上下移與置頂置底、複製、刪除、鎖定、隱藏、復原／重做（快照歷史，最多 80 步）、鍵盤操作（方向鍵、Delete、Ctrl+Z/Y/D、`[` `]`）、紙條文字自動縮放不超出、預覽模式、真正的 PNG 匯出、本機草稿與自動暫存。
- **作品管理**：作品清單、繼續編輯、複製（新 ID）、下載、刪除前確認（未下載過會提醒）。
- **我的時光盒**：日記新增／編輯／刪除、情緒與 1–5 強度、標籤、附上色盤與漂流瓶；關鍵字、日期區間、月份、情緒篩選；依月份的時間軸卡片。
- **雲端海洋**：公開列表、情緒篩選、隨機撿瓶、「我也有過這種感覺」、檢舉、刪除自己的作品；載入中／空資料／網路錯誤／權限錯誤狀態。未設定雲端時為明確標示的示範模式，不會假裝發布成功。
- **心緒探索**：7 個引導問題，可跳過、返回、提前結束，產生反思卡（存入時光盒或下載 PNG），明確標示非診斷。
- **今日色彩**：依情緒與強度產生 5 色色盤、可改色、複製 HEX、儲存、套用到漂流瓶背景或紙條、存入日記。
- **片刻**：真的在計時的呼吸練習（1／2／3 分鐘）、隨機原創短句、感受辨識、三分鐘書寫。
- **未來信件**：撰寫、設定閱讀日期、到期後再次開網站時提醒、提早打開、編輯、刪除、匯出。
### 延伸功能（第二版）

整體旅程分成四步，首頁上方會顯示每一步今天是否完成：**01 感受此刻 → 02 創作與安放 → 03 選擇是否分享 → 04 回望自己的旅程**。

- **此刻的心情天氣**（首頁）：選心裡的天氣（晴朗、多雲、起霧、下雨、雷雨、海浪、星夜）、情緒與強度，和 Open-Meteo 的外面天氣並排成卡片，例如「外面是晴朗，心裡還在下雨。」。可以存進時光盒（私人）、轉成漂流瓶，或下載 PNG。天氣取得失敗時卡片只寫「外面的天氣尚未取得」，不會編造。
- **隨機漂流瓶生成器**：首頁與工作室的「替我開啟一段心緒」，隨機組合場景、瓶身、紙條、裝飾與一句話，每個素材都可以再改。工作室有未儲存的修改時會先詢問。
- **漂流瓶的生命旅程**：每個作品的時間軸，包含製作、安放、漂流與共鳴（公開後顯示三種回應的人數）、回望。可以留下回望，也可以標記「想留給未來的自己」。
- **情緒星圖**（回望頁）：每篇日記或漂流瓶是一顆星，顏色代表情緒，同一種情緒的星星聚成星座。日記的星星越大代表當時強度越高，漂流瓶是四角星。可切換月份、點星星打開紀錄、用鍵盤操作，也有清單檢視。
- **情緒年度誌**（回望頁）：情緒分布、每月紀錄數、常用標籤與色彩、收藏的短句、想留給未來的作品。可以下載回顧卡片 PNG 或匯出 JSON。少於 5 筆時會寫明「資料還不多」，不下結論。
- **給過去的自己一封回信**：在任何一篇日記上寫回信，並排比較當時與現在的情緒、強度和需要。回信和日記存在一起，可以下載成信箋卡片。
- **海洋共鳴**：三種固定的溫和回應「我讀到了／我也有過這種感覺／願你慢慢好起來」，沒有留言、聊天或私訊。「今天的瓶子」每天給你一個別人的瓶子（不會是自己的），也可以把感動的瓶子收藏到書架。收藏的是當時的副本。
- **主題書架**（時光盒）：預設有想記得的事、給自己的話、曾經走過的低潮、海裡撿到的感動，可以新增、改名、刪除。日記、作品、收藏的短句、海裡的瓶子都能加入，刪除書架不會刪除原本的內容。
- **分享前的隱私檢查**：公開前掃描電話、手機、電子郵件、地址、身分證字號、網址、社群帳號、「我叫○○」等內容並標出位置，有發現時要另外勾選確認才能公開。也會用表格對照「只留給自己」和「放進雲端海洋」各自誰看得到、會包含什麼。
- **海洋聲景**：右上角「聲景」可以播放海浪、雨聲或夜晚蟲鳴，能調音量也能停止。預設關閉，只有你按下才會播放。聲音用 Web Audio 即時合成，不需要下載音檔。
- **草稿自動儲存與備份提醒**：工作室持續自動暫存。私人紀錄有 3 筆以上而且從沒備份，或距離上次備份已經 14 天時，首頁與時光盒會提醒你匯出，也可以選擇七天後再提醒。

- **設定**：動畫偏好（跟隨系統／減少／完整）、匿名代號、Supabase 連線、全部資料 JSON 匯出／匯入、清除本機資料、隱私說明。

### 第三版：動線、保存與隱私的打磨

這一版不再增加同類功能，而是讓既有功能更容易找到、更可靠，也更能串成一段完整的體驗。

- **導覽改成三個主要任務**：「創作與安放」（工作室、隨機生成、一鍵心緒卡、今日色彩、心緒探索、片刻）、「閱讀與共鳴」（雲端海洋、今天的瓶子）、「回望與收藏」（時光盒、我的漂流瓶、情緒星圖、年度誌、主題書架）。桌面是下拉選單，可用方向鍵移動、Esc 關閉；手機選單直接展開全部項目。設定改成右上角的齒輪。
- **首頁依序排列**：主視覺與邀請 → 上次沒完成的瓶子（「繼續編輯」）→ 四步旅程（標示「下一步」）→ 此刻的心情（一鍵心緒卡）→ 最近的紀錄與延伸探索 → 天氣、短句與色彩。
- **保存狀態看得見**：工作室顯示「已儲存／有未儲存的修改／尚未存進時光盒／暫存失敗」，以及最後一次自動暫存的時間。打字停下 0.5 秒就自動暫存，切換分頁或關閉頁面前也會立刻寫入。作品還沒存進時光盒就要離開工作室時會提醒；關閉分頁時，瀏覽器也會詢問。
- **備份更容易找到**：時光盒上方固定顯示「資料只存在這個瀏覽器・上次備份時間・雲端是否連線」與匯出按鈕，設定頁也會顯示上次備份時間。
- **匯入更安全**：匯入前會檢查空備份、較新版本、損壞的紀錄與格式錯誤的區塊，並逐項說明。如果寫入途中失敗，會自動還原成匯入前的資料。
- **刪除分清楚本機與雲端**：刪除已公開的作品時，可以選「只刪除本機作品」或「本機與雲端都刪除」。生命旅程裡也能單獨「從雲端海洋收回」，時光盒的作品會留著。
- **公開前逐項列出**：作品名稱、心事全文、給自己的話、情緒標籤、整張畫面與日期，各自標明是「只有你看得到」還是「公開」。
- **手機快速創作**：手機預設只顯示畫布、背景、瓶身與紙條樣式、文字和下載。圖層、旋轉等設定放在「進階編輯」，桌面也可以切換，模式會被記住。手機上的按鈕至少 44px 高。
- **回望串在一起**：
  - 回信改成左邊當時、右邊現在。
  - 漂流瓶的回望可以下載「前後對照的回憶卡」，上方是當時的瓶子，下方是當時的心事和現在的回信。
  - 情緒星圖可以依月份、情緒、標籤篩選，鍵盤可用方向鍵依日期移動、Home/End 跳到最早或最新一筆。
- **一鍵心緒卡**：可以「換一句短句」，也可以選「只留給自己」，或用「想分享…」先轉成漂流瓶，再自己決定去處。
- **心緒誌**：
  - 期間可以選年份、最近 90 天或全部紀錄。
  - 新增每月代表作品，以及寫給自己的信。
  - 可以自己挑最多 4 筆紀錄放進回顧卡。紀錄太少時會顯示「目前累積的紀錄：N 筆」，不推論趨勢。
- **舒適度**：背景星塵可以在設定頁「完全關閉」，聲景仍預設靜音。

## 部署到 GitHub Pages

1. 建立 GitHub repository，把 `index.html`、`README.md`、`SPECIFICATION.md`、`supabase/`、`docs/` 放到根目錄。
2. Settings → Pages → Build and deployment → Source 選「Deploy from a branch」，Branch 選 `main`／`/(root)`。
3. 等一兩分鐘，網址會是 `https://<帳號>.github.io/<repo>/`。網站用 `#studio` 這類 hash 導覽，在子路徑下不需額外設定。

沒有雲端設定也可以完整使用創作、日記、色彩、反思、片刻、信件與天氣；雲端海洋會以示範模式顯示。

## 設定 Supabase（雲端海洋）

1. 到 [supabase.com](https://supabase.com) 建立專案。
2. **Authentication → Sign In / Providers**，開啟 **Allow anonymous sign-ins**。建議同時開啟 CAPTCHA 或保留預設的匿名登入頻率限制。
3. **SQL Editor** 貼上 `supabase/schema.sql` 全文執行（可重複執行）。
4. **Project Settings → API Keys** 取得 Project URL 與 **publishable key**（舊專案叫 anon key）。
5. 二選一：
   - 寫進 `index.html` 最上方的 `CLOUD_CONFIG`（所有訪客都會使用），或
   - 打開網站的「設定」頁貼上並按「儲存並測試連線」（只存在該瀏覽器，適合先測試）。
6. 用兩個不同瀏覽器（或一般視窗＋無痕視窗）測試：A 發布，B 在雲端海洋看得到、可以共鳴與檢舉，但不能刪除 A 的作品。

**絕對不要**把 `service_role` 或 `sb_secret_` 開頭的金鑰放進前端或 README。網站偵測到這類金鑰會拒絕儲存。

### 資料庫權限設計（`schema.sql`）

| 資料表 | 誰能讀 | 誰能寫 |
|---|---|---|
| `bottles` | 所有人只能讀「公開且未被隱藏」的作品；擁有者可讀自己的全部作品 | 已驗證（含匿名）使用者只能新增自己的作品；只能改／刪自己的作品；`owner_id`、`moderation_status`、`read_count`／`resonance_count`／`wish_count` 由資料庫決定，使用者無權寫入 |
| `reactions` | 只能讀自己的反應 | 只有 `read`／`felt`／`wish` 三種；同一人對同一作品的同一種回應只能一次（唯一限制）；只能對公開作品回應，只能刪自己的 |
| `reports` | 一般使用者完全無法讀取 | 只能新增，同一人對同一作品只能檢舉一次 |
| `public_bottles`（檢視表） | 前端讀取用，不包含 `owner_id`，另外算出 `is_mine` 與 `my_reactions`（自己送出過的回應種類） | — |

伺服器端保護（觸發器）：每個身分 10 分鐘最多發布 3 個、24 小時最多 20 個；被 3 個不同身分檢舉的作品自動隱藏，等待管理者處理；字數上限用 CHECK 限制。管理者在 Supabase SQL Editor 處理檢舉（指令附在 `schema.sql` 最後），前端沒有任何管理權限。

以上權限已在本機 PostgreSQL 16 模擬 Supabase 的 `anon`／`authenticated` 角色與 `auth.uid()` 實際測試過：偽造 `owner_id`、改審核狀態、改別人作品、刪別人作品、重複回應、送出不存在的回應種類、直接改回應數、讀取檢舉、未登入發布都會被拒絕；頻率限制、三種回應各自計數、收回回應後計數減少、三次檢舉自動隱藏都有作用。也測試過在舊版資料庫上再執行一次新版 `schema.sql` 可以直接升級。

**已經用舊版 `schema.sql` 建好資料庫的話**：在 SQL Editor 再執行一次新版即可，它會補上 `read_count`、`wish_count` 欄位，放寬回應種類，並重建 `public_bottles` 檢視表，原本的作品和共鳴都會保留。尚未在真正的 Supabase 專案上測試，接上後請依步驟 6 驗證。

## 天氣（Open-Meteo）

- 城市搜尋：Geocoding API `https://geocoding-api.open-meteo.com/v1/search`
- 天氣：Forecast API `https://api.open-meteo.com/v1/forecast`（`current=temperature_2m,apparent_temperature,relative_humidity_2m,weather_code,wind_speed_10m,is_day`）
- 預設城市臺中市，可搜尋其他城市，或在使用者確認後使用瀏覽器定位（座標只存在本機）。
- 失敗時顯示錯誤與重試，不顯示任何估計或範例數值。畫面顯示觀測時間與更新時間。
- 免費方案限非商業使用、每日 10,000 次以內，需標示資料來源（頁面已標示 Open-Meteo.com，CC BY 4.0）。

## 字體

標題與短句使用 **霞鶩文楷 TC（LXGW WenKai TC）**，由 Google Fonts 載入，SIL OFL 授權；介面文字使用 Noto Sans TC。規格書指定的辰宇落雁體沒有官方網頁字型 CDN，因此沒有直接載入。字體堆疊已預留 `"ChenYuluoyan"`：若你確認授權並自行放置字型檔，可在 `<style>` 加上 `@font-face { font-family: "ChenYuluoyan"; src: url("fonts/ChenYuluoyan.woff2") format("woff2"); }`，標題就會優先使用它。PNG 匯出會先等字體載入，字體載入失敗時改用系統中文字體，文字不會消失。

## 本機資料

localStorage 鍵值都有命名空間與版本欄位：`innerlab.diaries.v1`、`innerlab.bottles.v1`、`innerlab.palette.v1`、`innerlab.quotes.v1`、`innerlab.letters.v1`、`innerlab.settings.v1`、`innerlab.studio.autosave.v1`、`innerlab.shelves.v1`（主題書架）、`innerlab.moodweather.v1`（心情天氣紀錄）。設定中另外記住：上次備份時間、工作室模式（快速／進階）、背景星塵開關，以及每個期間挑選放進回顧卡的紀錄。日記的回信、作品的回望與「想留給未來」標記分別存在日記與作品資料裡，完整匯出／匯入都包含這些新資料。每筆資料包成 `{ schemaVersion, savedAt, data }`，讀取時逐欄驗證，損壞的資料會被略過而不會讓網站打不開。localStorage 不會跨裝置同步，請定期在設定頁匯出備份。

## 已知限制

- 雲端海洋需要你完成 Supabase 設定才會跨使用者分享；目前程式碼的雲端部分只對本機 PostgreSQL 驗證過權限，還沒在真實 Supabase 專案上端對端跑過。
- 匿名身分綁定瀏覽器；清除網站資料或換裝置後，無法再管理之前公開的作品。第一版沒有正式帳號與跨裝置同步。
- 頻率限制在資料庫觸發器中執行；更細的內容審核（關鍵字過濾、人工審核佇列）需要另外的 Edge Function 或後台，第一版未實作。
- 未來信件只會在你再次打開網站時提醒，靜態網站無法在瀏覽器關閉時寄信或推播。
- 隱私檢查是以規則比對常見格式的輔助提醒，抓不到所有可辨識個人的內容（例如只寫學校名稱或暱稱），公開前仍需要自己再看一次。
- 情緒星圖與年度誌只整理你自己寫下的紀錄次數，不是心理評估；頁面上都有寫明。
- 已在 Chromium（桌面 1366×900、手機 390×844 觸控）自動化測試，共 236 項全部通過。其中雲端流程用與 Supabase 相同介面的本機模擬伺服器，搭配真正的 supabase-js 2.45.4 測過，包括發布、三種回應、每日一瓶、收回、一起刪除和斷線。真正的 Supabase 專案、Safari、iOS、Android 實機尚未測試。

## 作品集介紹（可直接使用）

Inner Lab｜心緒研究所是一個以互動式漂流瓶創作為核心的情緒紀錄與交流平台。使用者可以自由組合瓶身、紙條、星光與海洋場景，創作並下載專屬作品，也可以把私人日記保存在本機，或在明確同意後把作品公開到雲端海洋。

技術上以單一 HTML 檔完成：SVG 互動畫布搭配 Pointer Events 處理拖曳、縮放與旋轉，快照式復原／重做，Canvas 分層繪製確保 PNG 匯出的中文不遺失；資料層以帶版本的 localStorage 保存私人資料，公開資料走 Supabase 匿名驗證，權限、頻率限制與檢舉處理全部在資料庫的 RLS 與觸發器中執行，而不是靠前端隱藏按鈕。

### 面試展示順序建議

1. 首頁：品牌定位、天氣與每日短句。
2. 工作室：加入素材、拖曳、縮放、旋轉、圖層、復原。

7. 回望：情緒星圖切換月份、點星星，年度誌下載回顧卡片。
