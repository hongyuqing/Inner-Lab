        Settings

        設定與資料管理

        外觀與動態

        減少動態效果時，星塵會停在原地不動；選「完全關閉」則不畫任何星塵。聲景預設靜音，右上角可以隨時停止。

        匿名代號

        公開漂流瓶時會顯示這個代號，不會使用你的真實姓名。

        雲端海洋連線（Supabase）

        填入 Supabase 專案的 Project URL 與 publishable（anon）金鑰後，即可跨使用者分享漂流瓶。請勿填入 service_role 或任何 secret 金鑰。資料表與權限設定請參考 README 與 supabase/schema.sql。

        匿名身分會綁定在目前的瀏覽器。清除網站資料或更換裝置後，可能無法再管理先前發布的漂流瓶。第一版不提供跨裝置同步。

        資料備份

        日記、作品、信件、收藏與設定都存在這個瀏覽器的 localStorage，不會自動同步到其他裝置。建議定期匯出備份。

        清除本機資料

        會刪除這個瀏覽器中所有 Inner Lab 的日記、作品、信件與設定，無法復原。已公開到雲端的漂流瓶不受影響。

        隱私說明

        • 私人日記、未公開作品、未來信件與反思紀錄只存在你的瀏覽器，預設不上傳。
        • 只有你在確認對話框中同意後，漂流瓶的標題、文字與設計才會公開到雲端海洋。
        • 公開內容只顯示匿名代號與日期，不會附上位置、電子郵件或日記內容。
        • 天氣功能只在你主動同意時才使用瀏覽器定位，座標只用來查詢天氣並存在本機。
        • Inner Lab 是情緒表達與自我整理的工具，不提供心理診斷或醫療建議。
